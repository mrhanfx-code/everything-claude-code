# Awesome DESIGN.md

## Overview

A curated collection of DESIGN.md files extracted from real websites. These files follow the Google Stitch DESIGN.md format - plain-text design system documents that AI agents can read to generate consistent, pixel-perfect UI.

## What is DESIGN.md?

DESIGN.md is a new concept introduced by Google Stitch. It's a markdown file that defines how a project should look and feel, specifically designed for AI agents to read and implement.

| File | Who reads it | What it defines |
|------|-------------|-----------------|
| `AGENTS.md` | Coding agents | How to build the project |
| `DESIGN.md` | Design agents | How the project should look and feel |

## When to Use

**Always** when you need design guidance:
- Building UI that matches existing websites

## DESIGN.md Format

Each DESIGN.md file includes:

### Frontmatter
```yaml
---
version: alpha
name: Brand Name
description: Brief description of the design system
---
```

### Colors
Comprehensive color palette including:
- Primary colors and variants
- Text colors (ink, body, muted)
- Surface colors (canvas, cards, dark)
- Accent colors and semantic colors
- Success/warning/error states

### Typography
Complete typography system:
- Display fonts (xl, lg, md, sm)
- Body text and UI fonts
- Font families, sizes, weights
- Line heights and letter spacing

### Components
Detailed component specifications:
- Buttons (primary, secondary, variants)
- Cards and surfaces
- Navigation elements
- Form inputs and controls
- Data visualization components

### Layout
Layout guidelines including:
- Grid systems and spacing
- Responsive breakpoints
- Component positioning
- Visual hierarchy

## Design System Features

### Color Systems
- **Primary**: Brand colors with active/disabled states
- **Typography**: Ink, body, muted, and strong variants
- **Surfaces**: Canvas, cards, and dark mode options
- **Semantic**: Success, warning, error colors

### Typography
- **Display**: Slab-serif or sans-serif headlines
- **Body**: Humanist sans for readability
- **UI**: Clean interface fonts
- **Code**: Monospaced fonts for technical content

### Components
- **Buttons**: Multiple variants with hover states
- **Cards**: Elevated surfaces with shadows
- **Navigation**: Consistent menu styling
- **Forms**: Input fields and controls
- **Data**: Charts and visualization components
