# UI/UX Pro Max

## Overview

AI-powered design intelligence for building professional UI/UX across multiple platforms and frameworks. Provides design system generation, industry-specific styling, and comprehensive UI/UX guidelines.

## When to Use

**Always** when requesting UI/UX work:
- Build, design, create, implement, review, fix, or improve any interface
- Landing pages, dashboards, mobile apps, web applications
- Design system generation and component libraries
- UI/UX analysis and recommendations

## Key Features

### Design System Generator
- **161 Industry-Specific Reasoning Rules**
- **67 UI Styles** (Glassmorphism, Neumorphism, Brutalism, etc.)
- **161 Color Palettes** (Industry-aligned)
- **57 Font Pairings** (Google Fonts optimized)
- **25 Chart Types** (Dashboard analytics)

### Multi-Platform Support
- **Web**: HTML+Tailwind, React, Next.js, Vue, Angular

## Implementation Guidelines

### For Web Development
- Use HTML + Tailwind CSS by default
- Specify framework: React, Next.js, Vue, Angular
- Follow accessibility guidelines (WCAG AA/AAA)
- Implement responsive design (375px, 768px, 1024px, 1440px)

### For Mobile Development
- iOS: SwiftUI with Apple Human Interface Guidelines
- Android: Jetpack Compose with Material Design 3
- Cross-platform: React Native or Flutter

### For Dashboards
- Choose from 25 chart types based on data complexity
- Apply executive dashboard patterns for C-suite interfaces
- Use real-time monitoring styles for operations

## Quality Assurance

### Pre-Delivery Checklist
- [ ] No emojis as icons (use SVG: Heroicons/Lucide)
- [ ] cursor-pointer on all clickable elements
- [ ] Hover states with smooth transitions (150-300ms)
- [ ] Light mode: text contrast 4.5:1 minimum
- [ ] Focus states visible for keyboard navigation
- [ ] prefers-reduced-motion respected
- [ ] Responsive breakpoints implemented

### Anti-Patterns to Avoid
- Bright neon colors for professional applications
- Harsh animations without user preference
- Dark mode without proper contrast
- AI purple/pink gradients for banking/finance
- Low contrast text on complex backgrounds
